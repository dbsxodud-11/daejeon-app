# 대전으로 가는 길

그르노블에서 대전까지 15,044km를 출발일부터 만나는 날까지 나눠서
지구본 위의 아바타가 매일 조금씩 이동하는 웹 앱입니다.
사파리에서 홈 화면에 추가하면 주소창 없는 전체 화면으로 열립니다.

아바타를 누르면 지금 있는 도시로 줌인해 들어갑니다. 도시 사진이 깔리고,
가운데 선 위에서 지난 도시와 다음 도시 사이 어디쯤인지 보여줍니다.

화면은 **날짜 하나**로 정해집니다. 선 위의 아바타를 좌우로 끌거나,
아래 날짜 띠를 밀면 그날로 옮겨가고 어느 도시였는지와 사진이 따라 바뀝니다. 자료가 올라온 날에는 점이 찍히고,
아직 안 온 날은 흐리게 가려 둡니다. 화살표로는 하루씩 옮깁니다.

오른쪽 위의 **출근 / 저녁** 버튼은 **그날** 올린 영상과 사진을 엽니다.
올리는 건 열쇠를 아는 사람만 할 수 있습니다.

지구본의 도착지 대전에는 **광서**가 분홍 테두리 동그라미로 기다리고 있습니다.
톡 누르면 며칠 남았는지 알려줍니다. 사진은 `gwangseo.jpg` 입니다.
걷는 아바타는 다 와 가면 광서와 겹치지 않게 마주 보는 자리에 멈춰 섭니다.

## 올리는 방법 (깃허브 페이지)

1. 깃허브에서 새 저장소를 만듭니다. 공개로 두어도 되고, 비공개면 페이지 기능에 유료 플랜이 필요합니다.
2. 이 폴더의 파일 전부를 저장소 최상단에 올립니다.
3. 저장소 Settings, Pages로 들어가 Source를 `Deploy from a branch`,
   브랜치를 `main`, 폴더를 `/ (root)`로 지정하고 저장합니다.
4. 1분쯤 뒤에 `https://<아이디>.github.io/<저장소이름>/` 으로 열립니다.

## 홈 화면에 추가

아이폰 사파리에서 주소를 열고, 공유 버튼을 누른 뒤 "홈 화면에 추가"를 고릅니다.
크롬이 아니라 반드시 사파리에서 해야 아이콘과 전체 화면이 적용됩니다.

## 지구본 돌리기

지구본을 마우스나 손가락으로 끌면 원하는 각도로 돌려볼 수 있습니다.
두 손가락(또는 Ctrl+휠)으로 확대할 수 있습니다.
아바타를 **끌지 않고 톡 누르면** 도시 화면이 열립니다.

## 영상·사진 올리기

영상과 사진은 Cloudflare R2 에 들어갑니다. 처음 한 번 차리는 방법은
`worker/README.md` 에 적어두었습니다. 다 하고 나면 거기서 나온 주소를
`index.html` 위쪽 `MEDIA_BASE` 에 넣습니다.

올릴 때는 주소 뒤에 `?admin=1` 을 한 번 붙여 엽니다. 그 폰에서는 계속 열립니다.
도시 화면의 **올리기** 버튼을 누르고, 열쇠를 한 번 넣어두면 다시 묻지 않습니다.
열쇠는 그 폰에만 저장되고 아무 데도 보내지 않습니다.

올린 것은 **도시 구간별 날짜로 묶입니다.** 치앙마이를 지나는 동안 올린 것은
치앙마이 화면에서, 델리를 지나던 때 올린 것은 델리 화면에서 나옵니다.
여정이 끝날 때쯤이면 도시별로 정리된 기록이 됩니다.

## 출발일·만나는 날 바꾸기

`index.html` 의 `cfg` 에 박혀 있습니다.

    const cfg={
      start: q.get('from') || '2026-09-09',
      end:   q.get('to')   || '2026-10-30'
    };

주소에 `?from=2026-09-09&to=2026-10-30` 같은 값을 붙여 열면
그 값이 기본값 대신 쓰입니다. (예전에는 이 값을 폰에 저장해 두었는데,
날짜를 고쳐도 옛 값이 계속 살아남아서 그만두었습니다.)

## 구간마다 속도 다르게 걷기

출발일만 고치면 "오늘 어느 도시인지"가 같이 밀립니다. 둘을 함께 맞추려고
기준점을 두고 그 사이를 선형으로 잇습니다. `cfg` 아래의 `PACE` 입니다.

    const PACE = [
      { city: '치앙마이', date: '2026-10-07' },
      { city: '하노이',   date: '2026-10-11' },
      ...
    ];

기준점을 넣은 도시는 그 날짜에 지나도록 일정이 맞춰집니다. 지금 남은 구간은
치앙마이에서 5일, 하노이 5일, 홍콩 5일, 타이베이 4일, 상하이 3일, 서울 1일로
끊어 두었습니다. 거리로만 나누면 서울에서 대전까지가 140km
뿐이라 하루도 안 걸려서, 서울인 날이 하나도 없이 건너뛰어졌습니다.
비우면 출발일부터 도착일까지 거리에 비례한 일정한 속도가 됩니다.

## 파일

    index.html              앱 전체. 지형 데이터와 계산이 모두 이 안에 들어 있습니다.
    manifest.webmanifest    앱 이름, 아이콘, 전체 화면 설정
    sw.js                   오프라인 캐시. 한 번 열어두면 비행기 안에서도 열립니다.
    icon-180/192/512.png    홈 화면 아이콘
    avatar-me.jpg           지구본 위와 도시 화면의 선에 올라가는 얼굴
    photos/                 도시 배경 사진 15장. 이름 규칙은 그 안 README 참고
    worker/                 영상·사진 저장소. 차리는 방법과 시험용 페이지

## 바꿀 만한 곳

경로 도시 목록과 좌표는 `index.html` 안의 `DATA.cities` 배열에 들어 있습니다.
각 항목의 `km`은 그르노블에서부터의 거리이고, `x`와 `y`는 지도 위 좌표입니다.
도시를 더하거나 뺄 때는 이 배열만 고치면 도착 일정과 지도가 함께 따라갑니다.
도시를 더했으면 `photos/` 에 같은 규칙의 이름으로 사진도 넣어주세요.

`sw.js` 는 다른 도메인 요청을 **일부러 가로채지 않습니다.** 가로채면 맨 처음
받은 목록이 캐시에 굳어서, 새로 올린 영상이 영영 보이지 않습니다.
